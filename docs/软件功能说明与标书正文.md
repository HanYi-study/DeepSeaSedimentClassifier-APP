# 深海底质分类软件（DSSC）功能说明与标书正文

---

## 一、软件概述

**软件名称**：DeepSea Sediment Classifier（DSSC）—— 深海底质智能分类系统

**技术路线**：基于多波束后向散射（MBES Backscatter）与浅地层剖面（Sub-Bottom Profiler）声学数据，结合 MSC-Transformer 深度学习模型（参考 Wang et al., JMSE 2023），实现海底沉积物类型的自动分类与空间制图。

**开发框架**：Python + PyQt5 + PyTorch + Matplotlib，模块化架构，支持二次开发与功能扩展。

**运行环境**：Windows / Linux，支持本地 CPU 训练与远程 GPU 加速。

## 二、标准化基础功能

### 2.1 数据导入

本软件具备完整的多源数据导入能力，支持以下数据格式：

| 数据类型 | 格式 | 说明 |
|---------|------|------|
| 测线数据 | TXT (CSV) | 经度、纬度、反射强度、采样序号 |
| DEM 底图 | GeoTIFF (.tif) | 多波束后向散射镶嵌图，支持地理参考 |
| 浅剖数据 | SEG-Y (.seg/.sgy) | 浅地层剖面仪原始道集数据 |
| 模型权重 | PyTorch (.pt) | 已训练的分类模型权重文件 |

**数据导入功能特色**：
- 测线数据支持自定义列映射与分隔符自动检测
- 合并测线数据自动拆分为独立航带（基于 GPS 跳跃检测）
- SEG-Y 道头解析与坐标提取
- 大数据量惰性加载机制（30 万行 < 1 秒）

### 2.4 人机交互

软件提供完整的人机交互界面，涵盖分类全流程的参数配置与过程控制：

#### （1）模型权重管理

- **重新训练模式**：从零开始训练新模型
- **使用已有权重模式**：导入预训练 .pt 文件直接进行分类预测
- 训练完成后自动保存最佳模型
- 支持权重文件的导出与导入

#### （2）分类参数配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 学习率 (Learning Rate) | 0.001 | AdamW 优化器初始学习率 |
| 训练轮数 (Epochs) | 30 | 完整遍历训练集的次数 |
| 批次大小 (Batch Size) | 512 | 每次迭代处理的样本数 |
| 隐藏维度 (Hidden Dim) | 128 | Transformer 内部表示维度 |
| 注意力头数 (Num Heads) | 4 | 多头自注意力头数 |
| Transformer 层数 (Num Layers) | 2 | 编码器堆叠层数 |
| Dropout | 0.1 | 正则化丢弃率 |
| 训练集比例 (Train Split) | 0.8 | 训练/验证集划分比例 |

#### （3）GPU 计算配置

- 远程服务器 GPU 型号与显存自动识别
- 远程训练：SFTP 上传数据 → GPU 训练 → 下载模型 → 远程清理
- 实时流式回传远程训练日志
- 支持指定 GPU 卡号（CUDA_VISIBLE_DEVICES）

## 三、技术架构

### 3.1 核心算法

**MSC-Transformer 深度学习分类模型**（参考 Wang et al., JMSE 2023, 11(5): 1074）：

```
输入特征 (7-14维)
    ↓
Input Embedding (Linear → LayerNorm → GELU)
    ↓
Positional Encoding (可学习)
    ↓
Transformer Encoder × N (Multi-Head Self-Attention + FFN)
    ↓
Attention Pooling (加权池化)
    ↓
Classifier (LayerNorm → Linear → GELU → Dropout → Linear → Classes)
    ↓
5-10类沉积物概率输出
```

### 3.2 特征工程

| 数据源 | 特征维度 | 特征内容 |
|--------|---------|---------|
| TXT 测线 | 7 维 | 反射强度、深度、强度梯度、局部粗糙度、平滑强度、经度、纬度 |
| SEG 浅剖 | 13 维 | 振幅统计(mean/std/max/RMS) + 偏度峰度 + 总能量 + 峰值位置 + 过零率 + 分层能量比 + 反射界面梯度 + 位置 |

### 3.3 软件架构

```
DeepSeaSedimentClassifier/
├── config/settings.py         # 全局配置
├── core/                      # 核心模块
│   ├── data_loader.py         # 数据导入 (TXT/TIF/SEG-Y)
│   ├── data_processor.py      # 特征提取
│   ├── classifier.py          # 分类器封装
│   ├── seg_reader.py          # SEG-Y 读取
│   ├── seg_processor.py       # SEG 特征提取

│   ├── backscatter_profile.py # 后向散射剖面
│   ├── gpu_manager.py         # GPU 管理 (本地+远程SSH)
│   ├── env_checker.py         # 环境检查
│   └── exporter.py            # 成果导出
├── models/
```

## 四、软件特色与创新点

1. **多源数据融合**：同时支持 TXT 测线数据、GeoTIFF 底图、SEG-Y 浅剖数据，覆盖 MBES 与 SBP 两种主流声学数据源。

2. **MSC-Transformer 深度学习分类**：基于 Transformer 架构的沉积物分类模型，相比传统 CNN/RNN 具有更强的序列特征提取能力。

3. **远程 GPU 训练**：支持通过 SSH 连接远程 GPU 服务器执行训练，本地仅需数据上传和模型下载，远程服务器即用即删，不留数据残留。

4. **完整的人机交互**：参数可视化配置、实时训练监控、环境自动检查与修复、类别勾选定制。

5. **专业预处理模块**：去均值、中值滤波、高斯平滑、AGC、道间均衡等海洋声学数据标准处理流程。

6. **标准化成果输出**：GPS 标记分类图、统计报告、高分辨率地图、可复用模型权重。

7. **模块化可扩展架构**：核心算法与界面分离，支持二次开发与功能定制。
